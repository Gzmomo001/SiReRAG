Smartphone
The Ericsson R380 (2000) by Ericsson Mobile Communications. The first device marketed as a ``smartphone '', it was the first Symbian - based phone, with PDA functionality and limited Web browsing on a resistive touchscreen utilizing a stylus. Users could not install their own software on the device, however. The Kyocera 6035 (early 2001), a dual - nature device with a separate Palm OS PDA operating system and CDMA mobile phone firmware. It supported limited Web browsing with the PDA software treating the phone hardware as an attached modem. Handspring's Treo 180 (2002), the first smartphone that fully integrated the Palm OS on a GSM mobile phone having telephony, SMS messaging and Internet access built in to the OS. The 180 model had a thumb - type keyboard and the 180g version had a Graffiti handwriting recognition area, instead.
